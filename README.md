## Preview locally
Keep the folder structure intact, then open `index.html` in a browser.

## Publish with GitHub Pages
1. Upload the contents of this folder to your `FUTURE_FS_01` repository.
2. Keep the `assets` folder beside `index.html`.
3. In GitHub, open Settings → Pages and choose the deployment branch/folder.
4. Save and wait for the published URL.
